Generate and refine blog posts with AI. Pick a category, get topic ideas, queue SEO-optimized posts with images, and schedule creation in WordPress.

== Description ==

AutoPost AI is your personal content assistant for WordPress. Designed for bloggers, marketers, and business owners, this plugin lets you:

* Generate intelligent topic suggestions for a selected category.
* Build and manage a content queue.
* Automatically **create** full-length blog posts (drafts) using ChatGPT.
* Add contextual images from Pixabay (with a local placeholder fallback).
* Schedule post **creation** so drafts arrive on a consistent cadence.
* Trigger "Create Now" for any queued topic with one click.
* Optionally append a custom CTA block to each post.
* Receive optional email notifications when a new draft is created.

**Save time. Stay consistent. Grow your site.**

== Installation ==

1. Upload the plugin folder to the '/wp-content/plugins/' directory.
2. Activate the plugin through the "Plugins" menu in WordPress.
3. Go to **AutoPost AI** in your dashboard to begin setup.
4. Enter your OpenAI API key to enable AI content generation.

== Frequently Asked Questions ==

= Do I need an OpenAI account? =
Yes. You’ll need an OpenAI API key to generate content.

= Will this plugin automatically publish posts? =
No. The plugin creates drafts (on a schedule or on demand) so you can review and publish manually.

= Can I create a post immediately without waiting for the schedule? =
Yes. Use the **Create Now** button in the queue.

= Where do the images come from? =
AutoPost AI pulls relevant images from Pixabay. If none are found, a placeholder is used so you can update them later.

= Does it support custom post types? =
This version creates standard blog posts.
